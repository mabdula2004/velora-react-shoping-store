A new step in my full-stack learning journey: VELORA, a React fashion-store frontend.

I wanted this project to go beyond a static shopping page, so the experience includes:

• Product search, filters and sorting
• Product details with size and colour selection
• A wishlist and shopping bag that survive page refreshes
• Quantity controls and delivery calculations
• Login and registration UI with form validation
• A complete demo checkout and order-confirmation flow
• Responsive layouts and subtle animations

Built with React, JavaScript, React Router, Vite and CSS. The code is split into reusable components, with comments and a learning guide to make the UI/state connection easier to follow.

This is the frontend phase. Real authentication, a database, payments and order processing will come in a later backend phase.

The video shows actual screens from the working project, edited into a short showcase.
